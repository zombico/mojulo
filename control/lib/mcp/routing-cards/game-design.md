→ `design_game`: the game rail. THEIR game (a hero with abilities, gear, levelling or a story): `design_game({ world: { name } })` first: nothing built; as its producer, ask its one question (`producer.ask`; rails and sizes: `gameworld-rails`). Then `get_game_vocab({ id: 'gameworld-guide' })`: the loop (world → direction → looks → motion → actions → adornment → systems → equipment). `{ ref, patch }` edits it, `{ ref, approve, revise }` takes the verdicts, `{ ref, run: true }` makes what is ready: a build is fast, show a draft, go on asking. ONLY one level and a simple goal (reach, collect, race, sneak, shoot, rhythm, defend, farm, fly…; a car; a sport: `meet`, or `contest` with a `sport`, house rules in `concept`; `tabletop`; in an office: `building`): `design_game({ quick: { goal } })`, read `get_game_vocab({ id: 'gameworld-quick-<goal>' })` only. World and levels from a sentence: `design_game({ compose: { prompt } })`. Foes: `gameworld-foes`; GTA-like: `gameworld-hijack-city`. (Levels already minted, joined → `create_game`.) Full family → `get_creative_toolset({ form: 'game' })`.
