Mint a 3D cityscape from a tiny RECIPE — the fractal-generation path. You pass a seed plus a few knobs; the substrate stores ONLY the recipe (no geometry) and regenerates the whole city deterministically on render, so it costs almost no tokens and the same seed always rebuilds the same city. The result is a live, dependency-free CSS preserve-3d HTML scene served at `/api/sketches/<ref>/scene` (open it / embed it in an <iframe>); same artifact system as the other illustration mints (persists with `manifest.kind === 'fractal-city'`). The generator recursively subdivides the ground into non-square blocks (a coherent street grid with sidewalks, 2-lane mains, stoplights, crosswalks, power lines), fills each block by a composition rule (1 large / 2 medium / 1 medium + 2 small / building + lot / 4 small / single-block megatower) with parking lots in the gaps, and skins every building with a randomized facade (glass curtainwall / punched / banded; brick masonry with arched windows + cornices for low-rise; balconies harmonized per building program; rooftop kit of cell towers / water tanks / satellite dishes / smoke stacks; entrances, fire escapes, dumpsters; cylindrical and setback skyscrapers). Reach for this on framing like 'generate a city / make a cityscape / a downtown / a 3D city block / an urban scene'.

## Parameters

Pass these via `compose_world`'s `overrides`, which deep-merges over the resolved theme pack's SLOTS — so each knob lives at its slot path, NOT flat at the top level (a flat `time:` or `anchor:` is silently dropped by the theme adapter; the mint note flags it). City knobs ride two slots: `context` (time / locale / climate / massing) and `asset` (anchor / monument / civic areas / element toggles). Render channels (`fog`, `audio`, `region`, `viewBox`) ride the top level of `overrides` — they are render knobs, not theme roles. `seed`, `title`, `ref`, `folder_ref` are top-level `compose_world` params. Example:

`overrides: { context: { time: 'night', locale: 'east-asia' }, asset: { anchor: 'tower', monument: 'cn-tower', civic: ['city-park'] }, fog: true }`

Operator parcels and the level-of-detail dial also ride the top level: `overrides: { blocks: [{ rect: { x: 4, y: 4, w: 8, d: 6 }, use: 'residential', fill: 'rows', label: 'old town' }, { rect: { x: 14, y: 4, w: 8, d: 6 }, use: 'commercial', storeys: [8, 14] }], fidelity: 'massing' }`

- `title` (string) — Title for the resulting sketch artifact (top-level `compose_world` param, not an override).
- `seed` (integer) — Top-level `compose_world` param. Deterministic seed — the whole city is a pure function of it. Same seed → same city.
- `asset.anchor` (string) — Optional dominant 'anchor manji' that anchors the scene: a big central tower, or a curved elevated freeway. Omit for an unanchored uniform field. The root tower is capped at the DEFAULT frame's footprint (10.2 × 6.12 city units, the default 30 × 18 region's 34 %) and a monument budgets off at most the default frame's short side, so a larger `region` means more city around the same tower, not a bigger tower.
- `asset.anchorSeat` (string) — Where the root tower sits vs the main crossing: `'centre'` (the original centred tower, which the main cross-streets clip around) or `'side'` (the tower is seated at the centre of a drawn quadrant — with `blocks`, the quadrant they cover least — and the main crossing FLANKS it, so the crossing stays a crossing and the tower reads as a landmark on a corner). Omit for the gate: `side` when `region` exceeds the default frame in either dimension, `centre` otherwise (every existing default-frame recipe stays byte-identical). Reported as `stats.anchorSeat` when side-seated. `fidelity` never changes it.
- `context.depth` (integer) — Quadrant recursion depth (default 2). Higher → more, smaller blocks.
- `context.density` (number) — Building density 0.2–1 (default 0.6).
- `context.baseScale` (number) — Object size vs. the fixed frame (default 1). VALUES BELOW 1 shrink every object while the camera and aspect ratio stay put, fitting proportionally MORE, smaller blocks in the same scene — a broad 'zoom out, show more'. It's a uniform similarity transform (the city is generated in an enlarged region, then scaled back down), so the harmonious relative scale of streets/buildings/props is preserved exactly; only how much city fits the frame changes. e.g. 0.6 ≈ ~2.8× the blocks at ~60% size. Above 1 zooms in (fewer, larger blocks). Deterministic per seed.
- `context.time` (string) — Optional daylight setting: 'day' (sun + rooftop light + building shadows + day sky) or 'night' (streetlamp pools + moonlight + starry sky). Omit for a neutral flat render.
- `asset.elements` (object) — Optional element toggles { name: bool }. Most city elements (buildings, roads, sidewalks, cars, streetlamps, …) are ON by default; pass `false` to drop one. STREETCARS are an opt-in exception — pass { streetcars: true } (aliases: tram / trams) to lay a tram line: a corridor boulevard runs straight down the city's longer axis with an uninterrupted double track, overhead wire, roofed boarding stops, and trams, and the rest of the city routes around its reserved strip. TOWNHOUSES are the other opt-in — pass { townhouses: true } (aliases: rowhouse / brownstone / dutch-row) to turn eligible residential blocks into continuous rows of attached rowhouse units (warm-masonry BROWNSTONE walk-ups with tall stoops, raised parlor doors, cheek-wall rails, and heavy cornices; MODERN-STACKED panel/glass townhomes with flat parapets, two grade-level doors per lot, low stoops, and cantilevered box-bays; or DUTCH ROW narrow brick canal-house units with pale trim bands, tight window rhythm, and stepped/neck/bell gable rooflines). A row runs along a block's long edge; a 'full' row is double-loaded (doors + stoops on both faces). Every unit box is annotated with its structure / style / unit index for downstream consumers. CIVIC DOMES are a third opt-in — pass { civicDomes: true } (aliases: rotunda / domes / civic / capitol) to re-tag a few of the city's largest plain buildings as neoclassical domed ROTUNDAS (a columned drum + pedimented portico under a dome), each in one of three dome forms (hemispheric capitol-stone / gilded onion / turquoise bulbous). Deterministic per seed; leaves every other building untouched. FRONTAGE — { frontage: true } (aliases: entrances / roadAware / parkingEntrances) — makes every building, tower and garage ROAD-AWARE: each mass records which of its four faces front a road (`roadFaces`) and its `front` (the face on the widest road, clear of and furthest from a junction box), and the facade's entrance / storefront / awning goes on that face — on no face when the mass fronts nothing — instead of the blind +y lobby. LARGE masses (a tower, or a footprint ≥ 6 units² at ≥ 3 units tall; never a cylinder, monument, religious place or rotunda) also get a PARKING ENTRANCE on the road face, one of four variations chosen per building: a recessed garage mouth with a chevron header and striped barrier arm, a down-ramp between curb walls with a 'P' sign, a porte-cochère (canopy on columns over a drive apron with bollards), or a two-lane drive-through arch with roll-up slats and a lit sign strip; each cuts the curb (a `curb-cut` tile bridging sidewalk to road) and no lamp, sign, tree or bin stands in that span. A mass on more than one road (the centred tower straddling the crossing) takes its portal on the longest approach and a pedestrian lobby on a second road face — never two portals on one box. A road that DEAD-ENDS into a large mass (the centred tower, a block a clipped street runs into) gets a DROP-OFF APRON at the stub: a paved tile the road's width from the face to the road end, a curb island with bollards or a planter, end bars, and no crosswalk or signal head on that last stretch. A cylinder takes its portal on a tangent podium. With `traffic` on, at most one static car sits at each portal — arriving on the curb-cut or departing just inside the mouth; the MOVING cars on the `/world` path are SIGNALISED: every crossing (and every T where a side street meets a wider one) carries a phase program — the long axis green, an all-red clearance, the other axis green, a seeded offset per crossing — and a car brakes to the stop line on red, queues behind the car ahead, pulls away on green and finishes a crossing it has entered, so perpendicular streams never share a junction box; avenues carry two opposing lanes, side streets one one-way lane each (alternating), and no lane runs through a building. The signal heads themselves stay static; cars do not yet turn into the portals. With `people` on, one or two idle pedestrians stand on the walk before each lobby door, never on a curb-cut; with `walkers` on, the walk loops keep off the curb-cuts and the rings that pass a lobby door come first. HOUSES are road-aware too: a town lot whose street edge is not a road while the opposite edge is turns to face it (the whole lot mirrored; `roadFaces` on the house, its `front` flipped); a lot whose only road is on a perpendicular edge keeps its row front. Every city minted from now on has `frontage: true` written into its manifest unless you pass `frontage: false`; recipes stored before this knob existed re-render exactly as before (the planner default is off). No rng draw: the roads and every other object are byte-identical with the flag on or off; the fidelity dial prunes the entrance dressing as furnishing and keeps the mass. Reported as `stats.frontage`.
- `context.locale` (string) — Optional regional cue (e.g. 'north-america', 'south-america', 'europe', 'eastern-europe', 'russia', 'philippines', 'middle-east', 'africa', 'southeast-asia', 'east-asia', 'himalaya', 'indochina'; aliases like 'us'/'japan'/'tibet'/'thailand' plus 'dutch'/'amsterdam'/'rotterdam'/'utrecht'/'belgium' normalize in) that gates locale-weighted building classes. Currently: seeds at most one 'religious place' (class:'religious') into the scene, its form chosen by locale — a CHURCH (chapel / gothic-revival basilica / Eastern-Orthodox five-dome, orthodox rising eastward), a MOSQUE (ottoman dome+four-minarets / persian pishtaq+bulbous-dome / west-african 'sahelian' mud mosque / javanese tiered-roof 'nusantara'; dominant in the Middle East, prominent in Africa / SE-Asia, rare in the West), or a BUDDHIST TEMPLE (East-Asian 'pagoda' tower / Theravada 'stupa' bell-dome / Himalayan 'tibetan' monastery; dominant across East Asia / the Himalaya / Indochina, rarer than even the mosque in the West). European-ish locale cues also turn townhouse rows on by default and strongly bias them toward DUTCH ROW facades unless { townhouses: false } is passed. Omit (or any unlisted region) → no locale-gated class. Deterministic per seed.
- `context.climate` (string) — Optional CLIMATE that gates the street-tree species mix (default 'temperate'). 'tropical' / 'equatorial' drop conifers and turn about half the trees into coconut PALMS (slender bowed trunk + a fountain crown of drooping fronds); the rest stay the broadleaf variety (cluster puffs, spreading canopy domes, weeping crowns, two-tier layered canopies, codominant 'V' trunks). 'temperate' keeps conifers and the broadleaf variety with no palms. Deterministic per seed.
- `asset.monument` — lowered to the mint's `landmark` knob. Optional named MONUMENT(s) that become the city's root anchor in place of the generic tower: the Taj Mahal ('taj'), the CN Tower ('cn-tower'), Tokyo Skytree ('skytree'), the Rogers Centre / SkyDome stadium ('rogers-centre' / 'skydome'), an open-air Roman amphitheatre ('colosseum'), a modern domed sports arena ('arena'), the Great Pyramid of Giza ('great-pyramid'), the Louvre Pyramid ('louvre-pyramid'), the Petronas Towers ('petronas-towers'), Elizabeth Tower / Big Ben ('big-ben'), Stonehenge ('stonehenge'), a Chinatown gate ('chinatown-gate'), the Arc de Triomphe ('arc-de-triomphe'), or the Mobile EDM Hall ('mobile-edm-hall'), or the Eiffel Tower ('eiffel-tower'). Pass an ARRAY for an adjacent cluster — e.g. ['rogers-centre', 'cn-tower'] for the Toronto pair. The monument(s) are sized to their real ground footprint and RESERVED on the grid before roads, so the streets route around them; the city stays organised around the cluster, which renders at recognizable silhouette fidelity in /scene and the traversable /world. Best paired with asset.anchor:'tower'. Deterministic per seed.
- `asset.civic` (array) — lowered to the mint's `civicAreas` knob. Optional list of CIVIC AREAS — landmark-like districts that take real surface area and get the SAME up-front reservation a monument gets: each is sized, RESERVED on the grid before roads, and the streets / sidewalks / power lines / trees route around it (no infrastructure runs through it). Unlike a monument they need no special silhouette — each is composed from existing city primitives. Kinds: 'town-square' (a paved civic plaza with a tree cluster, perimeter benches, and corner lamps; aliases square / plaza), 'school' (a campus: a schoolhouse building plus an open green yard with a playground; aliases campus / schoolyard), 'strip-mall' (a long low retail strip fronting a parking apron with cars; aliases retail / mall), 'city-park' (an open green space, greenery-first, that VARIES per seed — trees + shrubs scattered by a recursive fractal clump-scatter, with a pond, looping gravel trails, and a medium community-centre building each appearing probabilistically; aliases park / greenspace / commons / gardens). Each requested kind is placed at most once, into a distinct slice of the city AWAY from the centre, so it composes with a centred `asset.monument` and the anchor tower. A district that can't fit clear of the others is skipped (reported in stats.civicAreasSkipped). Deterministic per seed.
- `asset.edifices` (array) — lowered to the mint's `edifices` knob. Optional list of MINTED BUILDINGS to place in the fabric: `[{ ref, at?: [x, y], margin? }]`, each `ref` a stored `edifice` sketch (mint_solid kind 'edifice'), `at` the plot's min corner in city units (default: centred in the region), `margin` the sidewalk ring in city units (default 0.6). The building is converted from its feet into city units by one storey (0.82 units per 11 ft floor) and gets the SAME up-front reservation a monument gets — plot plus ring claimed before roads, so streets, blocks and props route around it — with its own facade, roof and textures appended to the scene. The building stays the edifice's own recipe: edit the edifice and the city re-renders. A ref that is missing or not an edifice refuses the mint by name. Advisory, never a refusal: an inset that overlaps a monument plaza or leaves the region is placed anyway and named in `stats.insets`.
- `blocks` (array | object) — Optional OPERATOR-LAID PARCELS, reserved before the roads. Top level of `overrides` (like `region`; it is geometry in the recipe's own frame, not a theme role). Canonical form: `[{ rect: { x, y, w, d }, use, fill?, storeys?, height?, density?, label? }]` in city units, the same frame as `region` and an edifice's `at`. Each block gets the SAME up-front reservation a monument plaza or civic area gets — claimed on the grid and added to the reserved list before the quadrant recursion runs, so cross-streets flank it, roads / sidewalks / power lines clip around it, and nothing from the recursion builds inside it — and is filled by its `use` through the existing fill rules: `residential` (fenced detached lots with yards; `fill: 'rows'` for attached townhouse rows, `fill: 'massed'` for low apartment masses), `commercial` (the city's massed composition: 1 large / 2 medium / 1 medium + 2 small / building + lot / 4 small, with alleys), `industrial` (the same composition pinned to a low band → wide sheds and a lot on a dark yard), `park` (lawn + fractal greenery with a pond / trails / community centre per seed; `fill: 'playground'` for a fenced pocket park), `plaza` (a paved square with trees, benches, corner lamps), `civic` (a set-back hall on a paved apron; `fill: 'school' | 'strip-mall' | 'town-square' | 'city-park'` runs that district builder instead), `empty` (a claimed vacant lot — nothing is built and the recursion stays out). A massed block (commercial, residential 'massed') is a COMPOSITION, never one monolith: it is cut into parcels along its long axis (an alley or a setback gap per cut) until each is building-sized, and one drawn parcel — not the centre — takes the top of the height band; an industrial block is two to four low sheds shoulder to shoulder along the back edge (industrial facade program, no apartment windows) fronting a parking-lot yard. `storeys: n | [lo, hi]` (1–40; one storey = 0.82 units) or `height: [lo, hi]` (units) is the height band for the massed uses; when the block names none: residential massed 2–5 storeys, commercial 3–9 units, industrial 1–2.2 units, a civic hall 2.5–4.5 units. `density` (0–1, default `1`: an explicit use asks to be built) is the per-parcel keep probability — the ONLY dice an operator block rolls: a 'houses' block rolls no park-pocket and no vacant-lot chance, and a `park` block asked for a `playground` that does not fit (needs 2.2 × 2.2 clear) is reported, never swapped for the big park. A block's masses are never re-tagged as the city's church / mosque / temple or civic rotunda. `label` is echoed in the report. Blocks are placed FIRST (before `asset.civic` districts), so an explicit parcel beats an auto-sited district. Coarser form: `blocks: { map: ['RRCC', 'PPZE'], gap? }` expands one block per lettered cell over the region (R residential, C commercial, I industrial, P park, Z plaza, V civic, E empty, `.` unzoned) on a rows × cols pitch with a street gap (default 3 units) between cells; row 0 is the far (high-y) edge, like a map; expansion happens at render time, so a later `update_sketch` of `region` re-lays it. Advisory, never a refusal: a block outside the region or over an earlier reservation (the monument plaza, a streetcar corridor, the corridor-side anchor tower, a plaza-mode edifice) is still placed and named in `stats.blocksLaid` — `{ index, label?, use, fill, rect, heightBand?, inside, overlapsReserved, masses, boxes, note? }` per block, `masses` being the building-scale volumes that actually stood on it and `note` saying why a built use laid none (an earlier reservation holds the ground / every parcel lost the density roll / too small for the fill) — so iterate with `update_sketch`. Laying blocks drops a THEME-implied root anchor (e.g. mars-colony's tower) unless the call names `asset.anchor` itself: an explicit block layout is the operator's anchor intent; a named tower is kept and seated in the quadrant the blocks cover least (a full-region map still loses the cells under it, reported). Deterministic per seed; absent ⇒ byte-identical city.
- `fidelity` (string) — Optional LEVEL OF DETAIL: `'full'` (default) | `'massing'` | `'skyline'`. Top level of `overrides`. Lower levels are a prune over the finished plan, not a different generation, so the SAME SEED at any fidelity is the SAME CITY — identical road skeleton, block layout, masses, anchors, landmarks, civic footprints and edifice envelopes — with less dressing. `massing` drops the street furniture (lamps, signs, signals, stop signs, power lines, bins, benches, playgrounds, fences, trees / palms / shrubs, tram poles and stops), the road markings (crosswalks, sidewalk joints, lot stripes, playground pads), alley stickers, townhouse dressing, static cars, cyclists and pedestrians, and renders buildings, towers, townhouses, houses and garages as plain tinted extrusions (no facades, roofs, balconies or rooftop kit); monuments, religious places and rotundas keep their forms. `skyline` also drops the small ground planes (alley floors, driveways, lawns, trails, shores) and garages, and merges each attached townhouse row into one mass. Roads and ribbons (including the freeway deck and tram tracks), sidewalks, junctions, lots, plazas, lawns, ponds and the ground plate survive at every level. Below `full` the plan produces no walker loops, car lanes or people, so `walkers` / `traffic` attach nothing on `/world`, and a `time: 'night'` city has no lamp pools (the night sky and moonlight still render). Reach for it for a scape looked at from further away, or a cheaper world under a large `region` / small `context.baseScale`. Reported as `stats.fidelity` + `stats.pruned` (what came off). Aliases: 'mass' / 'medium' → massing; 'far' / 'low' / 'silhouette' → skyline.
- `region` (object) — Optional world footprint { x, y, w, d } (default a ~30×18 block). Top level of `overrides`.
- `viewBox` (object) — Optional render viewBox { width, height }. Top level of `overrides`.
- `fog` (true | object) — Optional opt-in volumetric fog channel (see the raymarch effects layer). Top level of `overrides`; `true` for defaults or a tuning object validated by the mint.
- `clouds` (true | object) — Optional opt-in cloud deck over the city, fog's sibling on the same raymarch effects layer. Top level of `overrides`. `true` is the cheap default: an `undershot` plane deck (one intersection per pixel, no march) sitting above the tallest block, lit from below with the sun through the slab and faded to the horizon. `{ mode: 'full' }` spends the frame budget on the volumetric march (lit tops, shaded troughs, clipped behind towers by the fog occluder). Tuning: `base` / `top` (world units; default above the tallest block), `coverage` 0..1 (default 0.35), `sun` [x, y, z] toward the sun (default: the world's light), `color`, `density`, `scale` (noise frequency, smaller ⇒ bigger clouds), `drift` (0 = still), `maxDist`, `fade`. A bad value refuses the mint by name. Renders on the live `/world` path only; stills ignore it.
- `xr` (true | object) — Optional opt-in WebXR entry on the live `/world` page: a headset (Quest browser, Vision Pro Safari) walks the same scene with no engine — left stick moves on the gaze heading, right stick snap-turns, feet snap to the walk channel's floor. `true` for defaults or `{ eye, speed, snap }` (fallback eye height in world units when no ground probe exists; world units/s; snap-turn degrees). Top level of `overrides`, like `fog`; any World kind accepts it (also `?xr=1` on the URL). Stills ignore it.
- `audio` (object) — Optional world AUDIO channel (generic across every base; resolved on the live /world path): { soundtrack?: { beatsRef: '<stored beats ref>' } or an inline beats recipe (compositions loop), sfx?: { beatsRef? | cues?, on? }, footsteps?: true|{ step, jump, land }, wind?: true|{ level, freq }, bindings? (soundtrack channel macros) }. Validated at mint — an unknown beats ref or invalid recipe REFUSES the mint rather than storing a world that fails to render. Vocabulary: get_beats_vocab({ id: 'audio-beats' }).
- `ref` (string) — optional stable sketch ref.
- `folder_ref` (string) — optional sketch folder to file under.
