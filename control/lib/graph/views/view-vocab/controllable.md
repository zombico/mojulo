Mint a LIVE, INTERACTIVE world the user can DRIVE — the unified 'control a thing in a world' primitive (a person you walk, a drone you fly, a self-playing figure). Stores ONLY a tiny recipe (`kind: 'controllable'`); the traversable world regenerates deterministically on render at `/api/sketches/<ref>/world` (open it / embed it). Reach for this on framing like 'let me walk a character through X', 'fly a drone through the city', 'a controllable / playable / first-person world', 'move a thing around a scene'. NOT for a static look-at scene — that's create_fractal_city / create_sketch.

The world is a list of ENTITIES. An entity = a transform + a RULE (how it moves each frame) + a BODY (what it looks like). The CAMERA is just an entity too.
Rules: `glide` (free flight, momentum, no gravity — drones/spectator), `walk` (ground-locked, W/S move + A/D turn, drives a walk-cycle gait), `platform` (a tuned PLATFORMER character controller — gravity + jump with variable height, coyote time, jump buffering, air control; Space jumps. 3D-native, so a 2.5D side-scroller is just this with `strafe:0` + a fixed heading), `follow` (a chase camera slaved to a target entity), `clock` (autonomous frame playback — a self-walking figure), `static`.
Bodies (any other type is refused): `mesh` ({shape:'box'|'sphere', size|radius, color}), `figure-rig` ({figure:<name>} — a rigged figure in `figures`: a made character, a suit, a car), `figure-frames` ({figure:<name>} — a baked human figure in `figures`), `polygomer` ({figure:<name>} — a `polygomerRef` hero), `glyph` ({form, tint?}), `platform` (a mover's carrier deck; draws nothing), `none` (invisible — e.g. a first-person camera entity).
A made character as the hero: make it with create_character as a hero or a mascot, then `figures: { hero: { heroRef:'<its ref>', library:'quaternius-ual', clips:{ forward:'Jog_Fwd_Loop', idle:'Idle_Loop', leap:'Jump_Loop', boost:'Jump_Loop', squat:'Jump_Start', turn:'Walk_Loop', strafe:'Jog_Fwd_Loop' } } }` and the entity `{ id:'hero', pilotable:true, rule:{ type:'platform', speed:3.6, stride:3.3, jumpSpeed:6.5, collideRadius:0.3, collideHeight:1.7 }, body:{ type:'figure-rig', figure:'hero' } }` under `camera:{ rule:'follow', target:'hero', dist:5.5, height:2.4 }`. `clips` maps each runtime state to a clip the hero or the library has (an unknown name is refused, listing both); `moves` maps a state to a clip of the hero's own, played over the library's when the hero has it and skipped when not (a cast member's `{ stagger:'stagger', topple:'knockedOutDown', getup:'knockedOutUp', swing_neutral:'cross' }`). `walker: true` marks a figure that follows or stands and never pilots: it may be any rigged character, an animal made with its gaits (`motion: ['walk', 'trot']`) or a creature, on its own clips with no library (`clips:{ forward:'trot', turn:'walk', strafe:'trot' }`). A mascot plays its own clips, no library: `clips:{ forward:'run', idle:'idle', turn:'walk', strafe:'run', leap:'leap' }`. An animal is not a pilot yet and is refused; an animal mascot is (a 'fox mascot').
A body that TRANSFORMS (robot ↔ vehicle, a transforming suit): `figures: { bot: { transformer: { robot: { variable: { palette: 'federal' } } } } }` is a variable suit that folds into its waverider, `{ robot: { alien: { palette: 'void' } } }` an alien body of pointed shells that folds into a hover jetski; `transformer: { vehicle: { supercar: { preset: 'razor' } } }` a car that stands up into a robot (`scheme: 'rear-foot'`: its legs together are the car's rear, the head pops out of the middle), `{ vehicle: { craft: 'jetFighter' } }` a jet that does (`scheme: 'fuselage-fold'`, `fold: 'front' | 'back'`, `legs: 'stretch' | 'box'`: the nose or the tail hinges down, the legs are its engines or tuck in a box); a ride, a racer, a stored `vehicleRef`; `robot: { unitRef }` puts a stored suit inside. The entity carries `forms` in place of `rule`: `{ id:'bot', pilotable:true, forms:{ robot:{ rule:{ type:'platform', speed:9 } }, vehicle:{ rule:{ type:'fly', stallSpeed:30, maxSpeed:140, assist:'arcade' }, camera:{ dist:40, height:12 } } }, transformDur:0.8, body:{ type:'figure-rig', figure:'bot' } }` (a car's vehicle form `{ type:'drive', horsepower, mass, wheelbase, wheelRadius }`). B (the pad's L3) transforms: an invincible beat plays the figure's own sequence, then the form's rule takes over, the speed carried across.
Controls in the rendered world: W/S move, A/D turn, Q/E strafe, Space/Shift up-down (glide) or Space to jump (platform), mouse-drag to look; a clock world plays itself under orbit.
Because input makes it path-dependent the world is non-bakeable (the /svg + /scene tiers show only its initial frame); /world is the live tier.

## Parameters

Pass these via `compose_world`'s `overrides` (deep-merged over the theme pack). `seed`, `title`, `ref`, `folder_ref` are top-level `compose_world` params.

- `title` (string) — Title for the resulting sketch artifact.
- `entities` (array) — The things in the world (at least one). Each: { id, transform:{ pos:[x,y,z], heading?, pitch? }, rule:{ type, ...params }, body:{ type, ...} }. z is up; heading is yaw in radians. Rule params — walk: { speed, turn, stride }; glide: { accel, maxSpeed, damping }; platform: { speed, accel / decel (ground acceleration, units/s²: the run builds at accel and sheds at decel, default accel; in the air both scale by airControl and momentum carries through the jump; absent, the run is instant), jumpSpeed, gravity, fallGravity, jumpCut (release-to-shorten cap), coyote, buffer, airControl, turnMode:'tank'|'look', strafe, airJumps (jumps in the air after the ground jump, reset on landing; airJumpMult, default 0.9, of jumpSpeed), glideFall (a held jump caps the fall at this speed), move:'world' + moveYaw (W/A/S/D move in a fixed camera's frame and the body turns to face its run: pair with an `overhead` camera at the same yaw), move:'lane' + lane:[[x,y],…] (a side-scroller: A/D run along the polyline, W/S do nothing, the body is held on the line round its bends: pair with a `side` camera) }; walk also takes lookPitch:true (look mode: the mouse pitches it, for an `eye` camera); follow: { target:<entity id>, dist, height, shoulder, lead, lerp }; clock: { rate } (cycles/sec). Body — mesh: { shape:'box'|'sphere', size:[w,d,h] or radius, color }; figure-rig / figure-frames / polygomer: { figure:<name declared in figures> }.
- `camera` (object) — Optional camera entity (sugar). { rule:'follow'|'eye'|'overhead'|'side'|'glide'|'orbit', target?:<entity id>, dist?, height?, shoulder?, lead?, lerp?, lockTrack? }. `eye` is first person: it rides the target `height` above its position down its heading and pitch, `hideTarget: true` hides the body it rides in, and `mouseLook: true` captures the mouse (the pilot in turnMode 'look'). `overhead` is the ¾ top-down camera: `yaw` (the way up the screen points, default π/2 = north), `tilt` (below the horizon, default 60°, held short of straight down), `dist`, `lookH`, `lerp`; its yaw never follows the target. `side` watches a `move:'lane'` target square on from the right of its lane (so running forward runs right across the screen), swinging round bends at `turnLerp`; `dist`, `tilt` (default 0.2), `lookH`, `lerp`. With a `follow` rule + target it trails that entity (over-the-shoulder); omit entirely to keep the default mouse OrbitControls (good for a `clock` turntable). `lockTrack: true | { mix?: 0.5, dist?: 1.2, rate?: 4 }` (pairs with `lock`): while the pilot holds a target lock the look point blends toward the target and the chase pulls back, so both stay framed; eases in and out.
- `figures` (object) — Optional map of name → baked-figure SPEC, e.g. { male: { motion:'walk', proto:'male', frames:24 } }, or a made character ({ heroRef, library?, clips }, above). A `figure-frames` or `figure-rig` body references one by name. Baked at render time via renderFigureWorldFrames, so the manifest stays a recipe (no geometry stored). `proto`: 'male'|'female'; `motion`: e.g. 'walk'.
- `faces` (array) — Optional explicit static world geometry as baked face quads ({ corners:[[x,y,z]×4], fill, doubleSided? }). Omit to get the default checker floor (see `ground`).
- `ground` (object) — Optional default-floor spec when `faces` is omitted: { size, cell, colorA, colorB }. Builds a 2-tone checker plane at z=0.
- `worldFraming` (object) — Optional initial camera framing { cameraPosition:[x,y,z], lookAt:[x,y,z], horizontalFov }. A follow/orbit camera then takes over each frame.
- `viewBox` (object) — Optional render viewBox { width, height } (default 1120×780).
- `bg` (string) — Optional background color (default #0b1220).
- `game` (object) — Optional GAME level channel: mint this world as a game level. Either mechanics-authored ({ levelRef, mechanics:[{ kind:'reach-exit'|'survive'|'collect'|'hazard-damage'|'fail-on-death', … }], fall? } — verbs lower into world behavior + a synthesized contract; manuals via get_game_vocab, kits via get_game_vocab({scope:'kit'})) or a hand-authored contract ({ levelRef, consumes?, produces, on? }). Validated at mint; create_game re-validates against the game's actual store.
- `match` (object) — Optional "MAKE IT A MATCH" channel (pairs with `mapRef`, requires an explicit `ref`): mint this world AS a scored match level over a stored map with pilotable entities. `{ mode, space?, killTarget?, rivals?, teamNames?, allyCount?, foeCount?, side? }`. Modes: `solo` (1v1 — every roster body a pilot option + one enemy seat each), `practice` (solo, non-destructive drill, AI opens passive), `ffa` (a rival pool, everyone hunts nearest), `team` (allies vs foes, team victory), `watch_solo`/`watch_team`/`watch_ffa` (no pilot — all-AI bouts under a glide spectator camera). The mode AUTHORS the level: seats derived from the map's own pilotable roster ("never count suits"), spawn ring/arcs from the map's geometry (honoring its `arena`/`arenaSpawns` hints), the engine match layer (kill scoring, respawns, drop-in, fire-guard), and the `game:` contract with presets — so don't pass `entities`/`game`/`camera`/`faces` alongside it. `space:true` for maps with no floor (3D seek + z-spread spawns). Set `killTarget` (solo/ffa default 3, team 6, watch 5), `rivals` (ffa pool, default 5), `teamNames` (default BLUE/RED). Promote the minted levels via `create_game`; the pre-level pick screens come from the contract's slices (suits / duel_enemy / ffa_rivals / team_allies / team_foes / watch_*).
- `lock` (boolean | object) — Optional TARGET LOCK: `true` or `{ range?: 120, cone?: 60, release?: range×1.25, aimRate?: 8, los?: true, pitch?: true }`. Press C / middle mouse / pad R3 and the piloted entity locks onto the hittable nearest its aim axis (never self, an ally, or a vanished wreck; within `range` and the `cone` half-angle; line of sight unless `los:false`) and is eased to face it (heading + pitch at `aimRate`/s) — the reticle sits on it, strafing orbits it, mouse look stands down. Press again to cycle to the next by angle, or to release when nobody else is in the cone; a dead / vanished / out-of-`release` target or a pilot swap releases. A diamond LOCK bracket projects over the target. Pair with `camera.lockTrack` to frame both. Deterministic, replay-safe.
- `combo` (boolean | object) — Optional COMBO SYSTEM for every poise-bearing body: `true` or `{ hitstun?: { base: 0.5, decay: 1, min: 0.12 } | false, juggle?: { launch: 8, lift: 0.7, hitLift: 3, gravity: 1, g: 20, max: 5, land: 'knockdown'|'stand' } | false, scaling?: { perHit: 0.9, floor: 0.3 } | false, reset?: 0.3 }`. HITSTUN: every hit re-arms the stun at `base·decay^(n−1)` seconds (decay 1 = static; 0.85 = the stun shrinks the longer the combo runs; `min` floors it). JUGGLE: a verb with `strikeLaunch` (u/s, or `true` for the config's `launch`) throws the target airborne — gravity `g·gravity^(n−1)` (gravity 1.2 = less air time per hit), follow-ups lift it until `max` hits, landing is the knockdown (wake guard ends the combo) unless `land:'stand'`. SCALING: hit k of a combo deals `perHit^k` (floored). `reset` = seconds after recovery a hit still links. Per body: `body.combo: false` (immune — a boss) or an override object. Absent ⇒ the fixed stagger / topple chain as before.
- `mapRef` (string) — Optional TERRAIN INHERITANCE: the ref of a stored controllable world whose terrain this level rides. The minted manifest stays LIGHT — only this level's own keys (entities, game, camera, …) plus the ref; faces/colliders/lighting/arena hints merge in from the map at resolve time (this level's keys win, wholesale). THE way to mint N level variants over ONE map — one map row, N light levels, and a map re-mint flows terrain to every variant automatically. Don't pass `faces`/`ground` alongside it (they'd shadow the inherited terrain). Validated at mint (ref must exist, kind 'controllable'); the renderability check runs on the merged form.
- `audio` (object) — Optional world AUDIO channel (generic across every base; resolved on the live /world path): { soundtrack?: { beatsRef: '<stored beats ref>' } or an inline beats recipe (compositions loop), sfx?: { beatsRef? | cues?, on? }, footsteps?: true|{ step, jump, land }, wind?: true|{ level, freq }, bindings? (soundtrack channel macros) }. Validated at mint — an unknown beats ref or invalid recipe REFUSES the mint rather than storing a world that fails to render. Vocabulary: get_beats_vocab({ id: 'beats-world-audio' }).
- `ref` (string) — optional stable sketch ref.
- `folder_ref` (string) — optional sketch folder to file under.
