### An agent game studio: the person is sold the studio, the agent is told the compiler

Supersedes the person-facing half of "One name: a 3D compiler for agents" before it ships. "3D compiler" stays true
and stays the agent's word; the person reads what the compiler lets their agent do: run a game studio.

- **The one-breath answer** (`get_substrate`, the sentence the agent says when the person asks "what is mojulo?"):
  "it turns your agent into a game studio". You direct; the agent works through the studio's departments (direction,
  levels and worlds, characters, gameplay and feel, art direction, audio, writing, QA, shipping, the trailer), all
  writing into one recipe, so a game's bible, the level you play and the export agree. Play, Print, Read, Hear and
  Observe stay as what the studio makes, and "3D compiler for agents" follows as how the agent works with it. The
  `initialize` preamble and `forward_context` are unchanged: they speak to the agent.
- **`CLAUDE.md`**: "What this is" names the studio and its departments, with the compiler underneath; one copy rule
  for two audiences (the README, the plugin and the manifests speak to the person; the drawers speak to the agent;
  the one-breath answer is the bridge, so it and the README agree); and a golden rule: a capability joins a department
  and composes (reachable from the keys that compose it, read in its book, carried by its exports, checked by its
  audit), since the README's combinations stay true only while it holds.
- **`README-OUTLINE.md`** is reframed for the rewrite: the studio's departments as the reader's questions, each
  answered by a bible page beside the screen it describes; one game shown start to finish; a grid that changes one
  department at a time to show the combinations; rooms, prints, books and science simulations as the same studio's
  other outcomes; the compiler in How it works. The README, the npm README and the manifests follow it once the
  captures exist (its Appendix A).
