### An agent game studio: the person is sold the studio, the agent is told the compiler

Supersedes the person-facing half of "One name: a 3D compiler for agents" before it ships. "3D compiler" stays true
and stays the agent's word; the person reads what the compiler lets their agent do: run a game studio.

- **The one-breath answer** (`get_substrate`, the sentence the agent says when the person asks "what is mojulo?"):
  "it turns your agent into a game studio". You direct; the agent works through the studio's departments (direction,
  levels and worlds, characters, gameplay and feel, art direction, audio, writing, QA, shipping, the trailer), all
  writing into one recipe, so a game's bible, the level you play and the export agree. Play, Print, Read, Hear and
  Observe stay as what the studio makes, and "3D compiler for agents" follows as how the agent works with it. The
  `initialize` preamble and `forward_context` are unchanged: they speak to the agent.
- **`CLAUDE.md`**: "What this is" names the studio and its departments, with the compiler underneath; one copy rule
  for two audiences (the README, the plugin and the manifests speak to the person; the drawers speak to the agent;
  the one-breath answer is the bridge, so it and the README agree); and a golden rule: a capability joins a department
  and composes (reachable from the keys that compose it, read in its book, carried by its exports, checked by its
  audit), since the README's combinations stay true only while it holds.
- **`README-OUTLINE.md`** is reframed for the rewrite: the studio's departments as the reader's questions, each
  answered by a bible page beside the screen it describes; one game shown start to finish; a grid that changes one
  department at a time to show the combinations; rooms, prints, books and science simulations as the same studio's
  other outcomes; the compiler in How it works.
- **The README and the manifests follow it.** The README opens "Turn your agent into a game studio. You direct; it
  builds." over the stealth-base session (a real one: the pitch, the world's book approved, four levels built, its time
  and cost), asks for games first (the base, a kart racer, a city), lays the departments out as a table with what each
  does and where to read more, and then the same studio beyond games (the floor plan, the oak table, the Pi tray); the
  compiler moved to How it works, and the quickstart's first ask is a game. The npm README's lead, the Claude plugin's
  README and manifests, `package.json`, `server.json`, `glama.json` and the dashboard's meta description say the same.
  The department cards with a bible page beside each screen wait on their captures.
- **Six departments, proving what the studio builds.** The departments are worlds and levels; characters, props and
  vehicles; play modes, animation and sound; foes and bosses; cameras and cutscenes; and game design and production,
  which ties them into the game's bible. QA, shipping and the trailer stop being departments: the audit and the engine
  legs are how everything the studio builds holds up, told in How it works and Where it goes. The README opens on the six
  things it builds, its departments table sits under the quickstart, and the one-breath answer, `CLAUDE.md`, the npm
  README, the plugin README and the outline name the same six.
- **Fixed after a blind read against the code.** The departments table no longer links cameras to the broadcast doc or
  game design to the press (the stealth base's book is the bible's example); worlds name the ground and what grows on it,
  and characters their acting faces (expressions, a facial-capture take saved with its voice). The stealth session's
  cost line says what it wrote to the cache (107k) apart from its output (9k), and the opening no longer says one
  sentence changes the game "wherever it shows".
