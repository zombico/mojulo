### A 3D creative studio: the pieces it makes, from an object up to a game

Supersedes the person-facing frame of "An agent game studio" before it ships. "Game studio" boxed mojulo into one
outcome; the person now reads that it makes 3D objects, characters, environments, interactive worlds and even
playable games, exported to their desktop. The departments stay how the agent works, and "3D compiler" stays the
agent's word.

- **The READMEs** (the repo's and npm's) open on "A 3D creative studio for your agent" and show what it makes piece by
  piece, from the easy to the hard: 3D objects, characters, vehicles and props, rooms and buildings, environments and
  levels, interactive worlds, playable games. Each piece says what the person gets, never how: no tool calls or
  recipe code, no departments or production machinery, no install weight. Where it goes (the browser, a desktop app,
  the engines, 3D tools, a printer) stays.
- **The one-breath answer** (`get_substrate`): "it turns your agent into a **3D creative studio**", with the order to
  open broad, ladder up from an object to a game, and say what the person gets; the departments are named as how the
  agent works, not what it sells.
- **The manifests** (`package.json`, `server.json`, `glama.json`, the marketplace entry) and the dashboard's page
  description say the same. The Claude plugin's own README and `plugin.json` wait for the next release, since a
  change under `plugins/mojulo/` needs the plugin's version raised.
- **`CLAUDE.md`**: "What this is" opens on the 3D creative studio; the copy rule says the person-facing pages open
  broad, ladder up and never say how.
