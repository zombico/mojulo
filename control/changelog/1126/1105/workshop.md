### The workshop: where a game is made and seen, said ahead of time

- **Where a big game is seen, said before it is built.** A cloud box builds any game and runs its machine gates, but a
  level reaches the creator from it only as a page under the host's limit, it draws WebGL in software, and it forgets
  its data when the session ends. `design_game`'s readout now carries a `workshop` step, first in `next`, when a level
  is estimated over the host's page limit and the creator is not on their own machine: the estimate is made from the
  recipe before anything is built (a glyph map's tiles by kind, at measured weights; game/workshop.js), the surface is
  the declared one, never sniffed. Its card, `gameworld-workshop` (served by id), gives the agent the words and the
  paths: carry the work to the laptop (recommended), download a desktop export for each look, or keep each level small.
- **The work packs into one file.** `npx mojulo script pack-data` (the repo: `node scripts/pack-data.mjs`) writes the
  database whole, checked and gzipped, to carry it from a cloud box to the laptop; the storage folder is named when it
  holds anything. Claude Code on the web's box row says it has no GPU (`gpu: false`). docs/workshop.md says it all for
  people.
