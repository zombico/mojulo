### The READMEs say the studio as it now works: five starts, a few questions first, a game to its first level

- **The README opens on the way a session goes.** You say what you want or pick one of five starts (a character, a
  game, an object, a 3D exhibit, a home or a room); you bring what you have (sketches, a floor plan, a document, a
  photo, a 3D model); for a game, a home or an exhibit the agent asks a few questions first and says back what it will
  make; then you look, play and change it by asking.
- **Games have their own section**: from an idea to a first level you play in one session, started from a kind of game
  you already know, delivered as a game (a start screen, menus, a HUD, pause, results and the next level), whole games
  from one sentence, and couch play for up to four on one screen or split screen.
- **The Claude Code plugin is the first way in for Claude Code**; `npx mojulo init` stays the way in for every other
  agent. The npm page and the plugin's README follow the same order, and the plugin's "Try it" starts from the starts.
- **Shorter.** The military-base walkthrough moved to the long tour (`docs/tour.md`); the README keeps one
  line for it.
- **Agent-facing docs follow.** `docs/AGENT-REFERENCE.md` opens on the starts and their producers, then the game
  rail; the retired surfaces are one paragraph. `AGENTS.md` says the starts and the producer-first rule.
- **Retired pages archived.** The README working outline is deleted; the contextmap, composer, app-runtime and an old
  clothing hand-off page move to `docs/archive/`, with a stub left where code still names the old path.
