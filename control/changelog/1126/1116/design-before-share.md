### Designing a game: the next question leads, and an early build is a draft

- **The studio asks the next design question instead of pushing to build.** When you are designing a game and
  something is still undecided (what game it is, how long, who the hero is, how it plays, the plan), the agent's
  list of next moves now carries that question. For a game you are designing page by page it comes before the
  build; for a game you asked to be made from a sentence it comes right after it.
- **An early build is a draft, and is said to be.** Building is fast, so the agent can build whenever there is
  something worth showing. A game built while those decisions are still open is no longer announced as complete
  with an offer to share it: it is shown as a draft, the next question is asked, and sharing waits until you ask
  for it. A one-level quick game is unchanged.
