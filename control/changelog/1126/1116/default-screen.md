### A new game is made for a wide screen

- **A game you start now opens wide, the shape of a monitor or a TV.** Until now every new game was made for a phone
  held upright unless you said otherwise, so a game first seen on a computer opened as a narrow strip. You can still
  ask for a phone or a tablet.
- **Games that run up the screen are still made for a phone.** An endless runner and an obstacle course are played
  upright, so they keep that shape unless you choose another.
- **Games you already made are unchanged.** Each keeps the screen it was made for.
