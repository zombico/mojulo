# Mojulo

**When the mojulo tools are available** (the mojulo MCP server's tools, such as `forward_context`):

1. If one of the start skills below covers the ask, use it: it names the entry tool to load and the steps. Do not read
   `forward_context` first.
2. Otherwise call `forward_context`, mojulo's routing index: find the row that matches what the user asked for and call
   the entry tool it names.
3. Pull a drawer or a vocab card only when that tool's result or the index points you there.
4. Iterate on the stored recipe in place (`update_sketch`, `edit_solid`) instead of minting again, and export with the
   tool the result names (`export_model`, `export_game`, `export_beats`). Give the user the file path from the result.

**Starts.** Each start has its own skill that knows its entry tool and its steps (a home or a room is two: the
building and the interior). With no ask yet, offer the five: a character, a game, an object, a 3D exhibit, a home or
a room.

- Make a character: the `make-character` skill (`create_character`).
- Design a game: the `design-game` skill (`design_game`).
- Design an object: the `design-object` skill (`mint_solid`).
- Make a 3D exhibit: the `make-exhibit` skill (`create_exhibit`).
- Design a home or a building: the `design-building` skill (`mint_building`).
- Design an interior: the `design-interior` skill (`design_interior`).
<!-- starts:end -->

**Sharing the work across models (Claude Code).** Spend the strongest model on design and run the rest light,
so the user's usage limits build more:

- Keep design with you: `cook`, `create_game`, `design_game`, `forge_plan`, `forge_publications`, `mint_catalyst`, `synthesize_abstract`, `verify_machina`.
- Hand one artifact to write or revise, with a clear brief, to the `mojulo-maker` subagent.
- Hand a batch of decided calls (exports, measures, lists, gathers) to the `mojulo-runner` subagent.
- A routing card or catalyst found by `semantic_search`, and every catalyst `list_catalysts`, `get_catalyst` and
  `recommend_catalysts` return, carries a `tier`: `design` stays with you, `judge` goes to `mojulo-maker`, `ride` and
  `fill` to `mojulo-runner`. A skill you materialize from a catalyst runs where its tier says.
- Read a manual yourself when you are about to author with it: what a subagent reads stays in its context.
- Make a single quick call yourself: starting a subagent costs more than one light call.

**When the mojulo tools are not available** (for example in a claude.ai chat, which does not start local MCP servers): tell the user that mojulo runs as a local MCP server in Claude Code, or in a Cowork session on their own computer, where this plugin starts it. Do not install anything or run commands to get it.
