# Design a building

Claude Code defers the mojulo tools' schemas: load the entry tool first with ToolSearch, `select:mcp__plugin_mojulo_mojulo__mint_building`,
and any other tool below the same way (or by a keyword search).

1. Ask what it is and how it is lived in or used: storeys, rooms, the site.
2. Mint it with `mint_building({ title, manifest })`. Its page is its structure book; ask the questions its outcome cards ask (concept, layout, drawings, build) and follow `next`.
3. Change it in place with `update_sketch`. To fit out one room, use the design-interior skill (`design_interior`).
4. Export with `export_model`: sheets, schedules, IFC or GLB.

## Routes

From mojulo's routing cards: which call the ask goes to, and where it forks.

**Mint a walkable house, apartment, furnished room, store, restaurant or mall** (`mint_building`)

→ `mint_building({ title, manifest: { seed, width, height, storeys: N, furnish: true } })` — the manifest is the recipe (`kind: 'floorplan'` may be left out); `rooms: [{ x, y, w, h, glyph }]` or `levels[]` author the plan. Its page is its structure book (a tab per concern). Four outcomes, a card each: Concept `house-concept`, Layout `house-livability`, Drawings `house-drawings`, Build `house-build`; ask its questions. `next` names what is open by outcome. Iterate with `update_sketch`; `export_model` ships it (`sheets`, `schedules`, `ifc`, `glb`). A store (`kind: 'store', card`), restaurant (`kind: 'restaurant', seed`) mall (`kind: 'mall', levels: 1 | 2`) or school (`kind: 'school-complex'`) mints the same way, read and graded as that building, its fit-out scheduled: card `building-commercial`. (Contrast: decorating one room → `design_interior`; an institutional block for a world → `mint_solid` kind `edifice`; a city / cave → `compose_world`; a PICTURE of a facade → `sketch_what_possible` `architecturalConstruction`.) Full family → `get_creative_toolset({ form: 'building' })`.

## Always

- Iterate on the stored recipe in place; a recipe is a starter, never minted again to change it.
- Two gates: the machine gate is measured, the eyes gate is the person looking. Say which ran; never claim the eyes gate passed. Give the person the page or the file path from the result.
- Unsure which tool fits? `forward_context` is the routing index.
- When the mojulo tools are not available (a claude.ai chat does not start local MCP servers): say that mojulo runs as a local MCP server in Claude Code, or in a Cowork session on their computer, where this plugin starts it. Install nothing.
