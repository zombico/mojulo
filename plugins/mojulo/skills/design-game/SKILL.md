# Design a game

Claude Code defers the mojulo tools' schemas: load the entry tool first with ToolSearch, `select:mcp__plugin_mojulo_mojulo__design_game`,
and any other tool below the same way (or by a keyword search).

1. Call `design_game({ world: { name } })` first: it builds nothing and answers the one question to ask (`producer.ask`). Ask one question a turn and call again with the answer.
2. Ask for what they already have (drawings, plans, documents) and pass it in; never guess what one would have told you. Each thing brought is recorded as placed or set aside, never dropped.
3. Place the game on a rail (`get_game_vocab({ id: 'gameworld-rails' })`) and call its size: a pixelizer game, a quick game or the full design loop. A one-level game asked for outright (a kart racer) is made at once: nothing to ask first.
4. Work the readout's `goalposts` to the first level. The machine gate proves it can be finished; the person approves it by playing it. Say which gate ran, never that it looks right.
5. Ship it: `export_game` for the web build, `export_model({ engine })` for a team's Godot, Unity, Unreal or Blender.

## Routes

From mojulo's routing cards: which call the ask goes to, and where it forks.

**Design a game — a hero, powers, gear and systems, made by the rail** (`design_game`)

→ `design_game`: the game rail. THEIR game (a hero with abilities, gear, levelling or a story): `design_game({ world: { name } })` first: nothing built; as its producer, ask its one question (`producer.ask`; rails and sizes: `gameworld-rails`). Then `get_game_vocab({ id: 'gameworld-guide' })`: the loop (world → direction → looks → motion → actions → adornment → systems → equipment). `{ ref, patch }` edits it, `{ ref, approve, revise }` takes the verdicts, `{ ref, run: true }` makes what is ready: a build is fast, show a draft, go on asking. ONLY one level and a simple goal (reach, collect, race, sneak, shoot, rhythm, defend, farm, fly…; a car; a sport: `meet`, or `contest` with a `sport`, house rules in `concept`; `tabletop`; in an office: `building`): `design_game({ quick: { goal } })`, read `get_game_vocab({ id: 'gameworld-quick-<goal>' })` only. World and levels from a sentence: `design_game({ compose: { prompt } })`. Foes: `gameworld-foes`; GTA-like: `gameworld-hijack-city`. (Levels already minted, joined → `create_game`.) Full family → `get_creative_toolset({ form: 'game' })`.

## Always

- Iterate on the stored recipe in place; a recipe is a starter, never minted again to change it.
- Two gates: the machine gate is measured, the eyes gate is the person looking. Say which ran; never claim the eyes gate passed. Give the person the page or the file path from the result.
